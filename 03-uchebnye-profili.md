# Профили для упражнения

Оба профиля вымышленные. Цифры и описание проектов заданы для учебного кейса. Их нельзя использовать как реальные кандидатские данные или подставлять вместо найденных людей в отчёт о поиске.

## Профиль A

Senior C++ Developer. 7 лет коммерческой разработки на C++.

Последние 4 года в маркет-мейкинговой компании. Разрабатывал обработчик рыночных данных и шлюз ордеров для фьючерсных бирж на C++20 под Linux. Сократил задержку tick-to-trade с 18 до 6 микросекунд по p99: убрал аллокации на горячем пути, перешёл на lock-free очереди, закрепил потоки за ядрами. Дежурил в торговые часы, разбирал инциденты с отклонёнными ордерами.

До этого 3 года в ad-tech: сервер аукционов с ответом до 10 миллисекунд, тоже C++.

Python использовал для скриптов анализа логов. Перенос стратегий исследователей в продакшен не описан.

Английский C1. Сейчас живёт в Варшаве. Готовность к релокации в Дубай не указана.

В хедж-фонде пришёл на позицию Quant Researcher: писал стратегии и бэктесты на Python (pandas, numpy), строил отчёты по доходности. Через год должность в профиле сменилась на Quant Developer, описание задач осталось прежним. Продакшен-торговлю сопровождает отдельная команда разработки.

В разделе навыков указаны C++, low latency, FIX, Kafka и Linux. C++ использовал в университете и в одном внутреннем инструменте для ускорения бэктеста. Коммерческая разработка на C++ и работа с задержкой в продакшене не описаны.

Английский B2, готов к релокации в Дубай.
