# Подготовка к практике

Пройдите шаги за 2 дня до встречи. Займёт около 20 минут. GitHub, терминал и другие AI-сервисы не понадобятся.

Понадобятся ноутбук на macOS или Windows, рабочий аккаунт Claude Team и Google Chrome.

Во время подготовки не загружайте данные реальных кандидатов, названия клиентов и выгрузки из Huntio.

## Чеклист готовности

Отметьте всё до встречи. В начале лекции каждый отвечает «готово» по пунктам.

- [ ] Claude Team: вход работает
- [ ] Claude Code открывается и отвечает на «привет»
- [ ] Лимиты полные: откройте `/usage` и проверьте остаток. Не тратите лимит за день до встречи, чтобы не остановиться посреди практики
- [ ] Расширение Claude in Chrome установлено, вход в тот же аккаунт и организацию
- [ ] Chrome залогинен в рабочий LinkedIn
- [ ] Материалы встречи: [репозиторий](https://github.com/Da6ka/lecture-ai-sourcing-practice), скачайте как ZIP (Code, Download ZIP)
- [ ] Пустая рабочая папка для практики
- [ ] Один реальный JD под вашу нишу в текстовом файле
- [ ] 2-3 ваших письма кандидатам, которые сработали
- [ ] Бесплатные аккаунты Granola, Juicebox и Metaview, если хотите повторять демо
- [ ] Плагин skill-creator установлен, если его ещё нет: `/plugin install skill-creator@claude-plugins-official` (команда из [документации](https://code.claude.com/docs/en/skills))
- [ ] По желанию: два экрана или два окна. В одном лекция, в другом можно повторять шаги за лектором

Подробные шаги для каждого пункта ниже.

## 1. Приложение Claude и вкладка Code

1. Скачайте приложение Claude для компьютера: [claude.com/download](https://claude.com/download). Если оно уже стоит, обновите его.
2. Войдите рабочим аккаунтом. Если у вас несколько организаций, выберите Lucky Hunter.
3. Откройте вкладку **Code** в верхней части боковой панели. Если видите предложение купить подписку, напишите организатору: значит, место в Team ещё не назначено.

Подробнее: [начало работы с приложением](https://code.claude.com/docs/en/desktop-quickstart).

## 2. Рабочая папка

1. Создайте на компьютере пустую папку `lh-proverka`.
2. Во вкладке Code под полем ввода выберите окружение **Local**, затем **Open folder** и вашу папку.
3. Режим разрешений поставьте **Manual**: Claude будет спрашивать перед каждым действием.

## 3. Расширение Claude in Chrome

1. Установите [расширение Claude](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn) или проверьте, что оно включено, если уже пробовали его.
2. Войдите в расширении тем же аккаунтом и той же организацией, что и в приложении. Если организации разные, Claude Code не увидит браузер.
3. Проверьте, что вы вошли в свой LinkedIn в этом Chrome.

Подробнее: [Claude Code и Chrome](https://code.claude.com/docs/en/chrome).

## 4. Проверочный запрос

Скопируйте во вкладку Code и отправьте:

```text
Проверь мою подготовку к учебной практике.
1. Найди в интернете страницу вакансий Lucky Hunter и выпиши её заголовок и ссылку.
2. Через расширение Claude in Chrome открой мой профиль LinkedIn и выпиши мою текущую должность.
3. Сохрани оба результата в файл proverka.md в этой папке.
4. Прочитай файл обратно и напиши, что получилось, а что нет.
Если какого-то инструмента нет, так и напиши. Ничего никому не отправляй.
```

Внимание: [пользовательское соглашение LinkedIn](https://www.linkedin.com/legal/user-agreement) запрещает скрейпинг и неразрешённую автоматизацию. Проверочный запрос только читает ваш собственный профиль, но любая работа с LinkedIn через Claude in Chrome идёт на ваш страх и риск: малые пакеты, без автоотправки.

Подготовка завершена, когда в папке появился файл `proverka.md`, в нём есть ссылка и ваша должность, а в Chrome открывалась вкладка с LinkedIn. Ответа «всё подключено» без файла недостаточно.

## Если что-то не работает

| Что случилось | Что делать |
|---|---|
| Вкладка Code просит подписку | Напишите организатору: нужно назначить место в Team |
| Claude не видит браузер | Проверьте, что расширение и приложение в одной организации. Перезапустите Chrome и приложение |
| Расширение недоступно для организации | Это настройка у владельца Team. Напишите организатору |
| Другая ошибка | Пришлите скриншот организатору. Без паролей и личных данных |

## Что будет на занятии

Материалы практики лежат в репозитории: скачайте его как ZIP (Code, Download ZIP) и распакуйте архив, откройте папку во вкладке Code (окружение Local, Open folder) и попросите Claude прочитать [START.md](START.md). Подключать ATS, почту и приватные профили не нужно, письма сохраним в локальные файлы и никому не отправим.

## 5. Анкета

1. Какие вакансии у вас сейчас в работе? Направление и грейд, без названий клиентов.
2. Что уже поручали Claude in Chrome или корпоративному GPT? Что сработало, что нет.
3. Где в сорсинге и аутриче вы теряете больше всего времени?
4. Через какие каналы чаще пишете кандидатам и какой отклик видите?
5. Что должно произойти на встрече, чтобы вы сказали: время потрачено не зря?
