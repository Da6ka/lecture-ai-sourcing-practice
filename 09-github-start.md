# GitHub: как забрать материалы лекции

GitHub хранит файлы и историю их изменений. Для этой лекции думайте о репозитории как о папке с материалами по одной ссылке.

- Репозиторий: весь комплект материалов.
- README: первая страница с объяснением, что и когда открывать.
- Файл `.md`: обычный текст с разметкой. На GitHub он отображается как документ.
- ZIP: копия комплекта файлов на вашем компьютере.

## Открыть и скачать

1. Перейдите в [репозиторий материалов](https://github.com/Da6ka/lecture-ai-sourcing-practice).
2. На первой странице прочитайте README.
3. Над списком файлов нажмите зелёную кнопку Code, затем Download ZIP.
4. Найдите скачанный архив и распакуйте его.
5. На 60-й минуте занятия, по сигналу лектора, откройте распакованную папку во вкладке Code приложения Claude: Local, затем Open folder.
6. Отправьте: `Прочитай START.md в этой папке и начни со мной учебную практику.`

Code на сайте GitHub открывает меню скачивания. Code в приложении Claude открывает рабочую среду. Это разные кнопки в разных приложениях.

Для получения нашего публичного комплекта не нужны регистрация на GitHub, установка Git, терминал или написание кода. Не загружайте свои резюме и переписки обратно в публичный репозиторий. Результаты практики остаются в локальной папке `results/`.

После скачивания файлы сами не обновляются. Новый ZIP распаковывайте в другую папку, чтобы сохранить свои результаты и правки.

[Официальная инструкция GitHub по скачиванию ZIP](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives).
