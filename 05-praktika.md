# Практика: поиск и аутрич через Claude

Откройте всю учебную папку во вкладке Code приложения Claude: окружение Local, затем Open folder. Работайте в одной сессии, чтобы Claude видел ваши уточнения.

Практика делится на две части. Минимум (шаги 1-3) проходят все. Бонус (шаг 4) для тех, кто успел.

## 1. Контекст и план

Отправьте:

```text
Помоги провести учебный поиск C++ Developer (HFT).
Прочитай 01-jd-cpp-developer-hft.md и 02-kriterii.md из рабочей папки.
Покажи короткий план: как будешь проверять профили и сохранять результат.
Назови, какие инструменты тебе доступны: веб-поиск, Claude in Chrome. Пока ничего не ищи.
Если есть вводные, без которых нельзя выполнить учебное задание, спроси. Условия учебного кейса не заменяй своими предположениями.
```

Проверьте, что Claude понял критерии, в том числе разницу между исследователем и разработчиком.

## 2. Минимум: разбор учебных профилей

```text
Прочитай 03-uchebnye-profili.md. Это вымышленные профили.
Оцени A и B по критериям файла 02-kriterii.md.
Таблица: профиль | критерий | статус | точная цитата | вопрос на скрининг.
Отдельно проверь коммерческий стаж на C++, стаж в HFT и кем человек работал: исследователем или разработчиком. Не считай список навыков доказательством опыта в продакшене.
Сохрани разбор в results/practice-review.md. В конце покажи места, где данных недостаточно.
```

Сравните выводы Claude с исходным текстом. Найдите одну ошибку или попросите конкретнее обосновать самый слабый вывод. Сохраните уточнение.

## 3. Минимум: сообщение кандидату

Для сопоставимого разбора используйте профиль A:

```text
Напиши заметку к приглашению в LinkedIn кандидату из профиля A по JD из 01-jd-cpp-developer-hft.md.
Пиши по-русски. Используй только факты этих файлов. Имя и подпись оставь заполнителями.
Сохрани первый вариант в results/outreach-v1.md. Ничего не отправляй.
```

Затем:

```text
Прочитай 04-obrazcy-pisem.md и подготовь новый вариант по правилам голоса бренда.
Кратко назови, что изменишь. Детали из образцов не переносить.
Проверь каждое утверждение о кандидате по профилю A, а каждое утверждение о роли по JD.
Сохрани новый вариант в results/outreach-v2.md, первый файл оставь.
Добавь в тот же файл follow-up через 3-4 рабочих дня и вариант для Telegram.
В results/outreach-check.md запиши, какие факты использованы, на что они опираются и какие мои правки сохранить для следующего запуска.
```

Сравните версии. Решите, какие правила стоит оставить, и попросите Claude записать их в `results/rules.md`.

## 4. Бонус: живой поиск

```text
Запускай поиск по согласованному плану.
1. Составь 2-3 boolean-строки для поиска в LinkedIn и список из 10 компаний-доноров. Сохрани в results/search.md.
2. Через веб-поиск найди до 3 публичных профилей разработчиков C++ из трейдинга: GitHub, личные сайты, выступления, Codeforces, LinkedIn. Рейтинг на Codeforces не подтверждает промышленный опыт.
3. Для LinkedIn используй Claude in Chrome: открывай не больше 3 профилей, по одному, только для чтения. Ничего не нажимай, не устанавливай контакт и не пиши сообщений.
Для каждого человека дай имя со ссылкой, источник, короткую цитату о релевантной работе и непроверенные требования.
Не делай вывод о полном соответствии по поисковому фрагменту. Если полный профиль недоступен, явно отметь это. Не придумывай людей и ссылки.
Сохрани кандидатов в results/candidates.md и прочитай созданные файлы обратно.
```

Откройте найденные ссылки сами. Проверьте один вывод по исходной странице. Если Claude ошибся, дайте ему конкретную обратную связь с цитатой.

Многие кванты почти не ведут публичных профилей. Если нашлось мало, это нормальный результат: сохраните причину в `results/search.md`.

## 5. The AI note

Напишите сами, без Claude, полстраницы в `results/ai-note.md`:

- **Что спросили:** ваш главный запрос к Claude своими словами.
- **Что получили:** коротко, что он выдал.
- **Что оставили:** и почему этому можно верить, например есть цитата и ссылка.
- **Что выбросили:** ошибки, выдумки, лишнее.

Это формат из тестовых заданий для кандидатов. Его же можно просить у кандидатов, чтобы видеть, как они работают с AI.

## 6. Разбор в группе

Покажите экран с одним примером: исходный ответ, ваше уточнение и новый результат. Обсудите, какая инструкция изменила работу Claude и как проверить, что он её выполнил.
