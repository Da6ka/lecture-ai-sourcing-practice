# Учебный пример HR-int-assessment

Все реплики и условия ниже вымышлены и составлены для демонстрации правил рецепта. Это не реальный кандидат и не запись интервью. Ожидаемый разбор написан при подготовке материалов, а не получен проверенным запуском в Granola. На слайде использовать подпись "Учебный пример".

Ситуация адаптирована из вымышленного примера автора: конкретная задача с данными и неполный рассказ об A/B-тесте. Названия клиентов, реальные требования вакансий и персональные данные не используются.

## 1. Параметры учебной роли в заметках

```text

Темы звонка: SQL и данные, A/B-тесты.
Жёсткие фильтры: нет для этого учебного фрагмента.
Язык: не оцениваем.
Компетенции с баллом 1-4:
SQL и данные | тема: SQL и данные | для балла 3: конкретная задача, собственные действия, причина расхождения и проверка результата.
A/B-тесты | тема: A/B-тесты | для балла 3: гипотеза, основная метрика, длительность, своё действие, решение и кто его принимал, ограничения.
Обязательные отметки: нет для этого учебного фрагмента.
Отметки без влияния на вывод: нет для этого учебного фрагмента.
Не оценивай: английский, другие компетенции, локацию и условия работы. В этом фрагменте их не обсуждали.

```

## 2. Вымышленный фрагмент транскрипта

Рекрутер: Расскажи про конкретное расхождение в данных. Что сделала сама и как проверила исправление?

Кандидатка: В одном отчёте выручка из BigQuery не сходилась с биллингом. Я сравнила записи по order_id и нашла повторные события после ретраев. Сама добавила дедупликацию в витрину, затем повторно сверила результат с биллингом на том же периоде. Расхождение исчезло.

Рекрутер: Теперь про конкретный A/B-тест. Какая была гипотеза, метрика, сколько он длился, что ты сделала сама и кто принял решение?

Кандидатка: Мы проверяли, повысит ли новая цена выручку с посетителя paywall. Я считала конверсию в подписку и смотрела её по сегментам.

Рекрутер: А длительность, итоговое решение и ограничения этого теста помнишь?

Кандидатка: Длительность и кто принял решение не помню. Ограничения сейчас не назову.

## 3. Сокращённый ожидаемый разбор для слайда

Это фрагмент оценки 2 компетенций, не полный ответ рецепта со всеми разделами.

**SQL и данные: 3/4.** Назвала конкретную задачу, сама нашла дубли по order_id, исправила витрину и повторно сверила результат с биллингом.

**Закрыто:** задача, собственные действия, причина расхождения, проверка результата.

**Не хватает:** нет по критерию учебной роли. Оснований для 4 нет: альтернативы, собственные ошибки и ограничения решения не обсуждала.

**A/B-тесты: 2/4.** Назвала гипотезу и свою работу с конверсией. Не назвала длительность, решение, того, кто его принял, и ограничения. Отдельно нужно уточнить соответствие метрики гипотезе о выручке.

**Закрыто:** гипотеза, названная метрика, собственные действия.

**Не хватает:** длительность, итоговое решение, ответственный за решение, ограничения.

**Предложение по решению: под вопросом.** По данным есть конкретный пример со своим вкладом и проверкой. Рассказ об эксперименте не покрывает критерии роли: это одна слабая компетенция. Итоговую оценку принимает рекрутер.

**На следующем этапе:** разобрать один эксперимент целиком, включая выбор метрики, длительность, ограничения и решение.

## 4. Что показать участникам

Слева фрагмент транскрипта, справа оценку с объяснением. Попросите найти, какие слова подтверждают 3 по данным и чего не хватает для 3 по экспериментам. Полный рецепт читать со слайда не нужно.

Не представлять ожидаемый разбор как результат живого запуска. Для демонстрации работы Granola отдельно выполните рецепт на доступной учебной встрече, сверьте результат с этими входными данными и сохраните фактический ответ.
