# Шпаргалка: лектор показывает Codex, вы работаете в Claude Code

Лекция 5 ноября 2026. На экране лектора — **Codex**, у участников — **Claude Code (Claude Team)**. Это не ошибка: мы повторяем **задачу и текст запроса**, а не кнопки другого приложения.

## До практики: что делать с GitHub

GitHub здесь — папка с учебными материалами, а не задание по программированию.

1. Если при подготовке вы уже скачали ZIP этого репозитория, **не скачивайте заново**.
2. Если нет: на странице репозитория нажмите **Code → Download ZIP**, затем распакуйте архив.
3. При подготовке вы уже создавали отдельную папку `lh-proverka` и файл `proverka.md` — **оставьте их как есть**. Не нужно перемещать `proverka.md` в материалы лекции или выполнять проверку снова.
4. До сигнала лектора можно просто открыть README на GitHub. Самостоятельно выполнять задания пока не нужно.

## Когда лектор скажет «начинаем практику»

1. Откройте Claude Desktop → вкладка **Code**.
2. Выберите **Local → Open folder** и **распакованную папку этого репозитория**, где лежит `START.md`. Не выбирайте прежнюю папку `lh-proverka`.
3. Отправьте в чат:

```text
Прочитай START.md в этой папке и начни со мной учебную практику. Сначала покажи план и дождись моего подтверждения.
```

4. Дальше идите по одному шагу вместе с лектором. Claude должен сохранять результаты в локальную папку `results/`, **не** отправлять их на GitHub.

## Перевод действий с экрана лектора

| Лектор в Codex | Вы в Claude Code |
|---|---|
| Открывает локальную рабочую папку | Code → Local → Open folder |
| Просит прочитать JD и критерии | Вставляете тот же промпт из `05-praktika.md` |
| Показывает оценку вымышленных профилей A и B | Проверяете те же исходные профили и сохраняете `results/practice-review.md` |
| Правит ответ агента | Указываете конкретную цитату и просите перепроверить вывод |
| Пишет outreach-v1 и outreach-v2 | Используете те же задания и сравниваете версии |
| Создаёт черновик SKILL.md | Создаёте `results/skill-draft/SKILL.md` — пока **не** устанавливаете его |
| Показывает публичную страницу или результат поиска | Смотрите принцип «источник → цитата → вывод → вопрос»; доступ к Chrome у вас может отличаться |

**Важно:** разные модели могут отвечать по-разному. Это нормально. У всех должны совпадать исходные данные, проверяемые критерии и названия файлов, а не формулировки ответа.

## Если что-то не работает

- Нет доступа к браузеру? Продолжайте на вымышленных профилях в `03-uchebnye-profili.md`.
- Claude не видит файлы? Проверьте, что открыта **папка с `START.md`**, а не одна вкладка с файлом.
- Нет `results/`? Попросите Claude создать эту папку.
- Не запускается skill-creator? Попросите Claude обычными словами создать `SKILL.md` по `06-svoj-skill-i-proverka.md`.
- Открылся запрос разрешений? Читайте конкретное действие и подтверждайте только безопасные чтение/запись учебных файлов; не разрешайте отправку сообщений или операции с аккаунтами.

**Правило занятия:** файл `proverka.md` уже доказывает, что вы умеете давать агенту задачу и получать созданный файл. Сегодня повторим цикл на задачах сорсинга и аутрича.
