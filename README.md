# AI для сорсинга и аутрича

На практике ищем C++ Developer (HFT) через Claude: вкладку Code в приложении Claude и расширение Claude in Chrome. Учимся ставить задачу, проверять найденное и готовить черновики сообщений.

## Порядок: что и когда открываем

Репозиторий открытый, аккаунт GitHub не нужен: [github.com/Da6ka/lecture-ai-sourcing-practice](https://github.com/Da6ka/lecture-ai-sourcing-practice).

**Шаг 0. За 2 дня до встречи, около 20 минут**
1. Нажмите зелёную кнопку **Code**, затем **Download ZIP** и распакуйте архив в удобную папку.
2. Откройте [00-podgotovka.md](00-podgotovka.md) и пройдите чеклист. Подготовка завершена, когда в рабочей папке появился `proverka.md`.

**Шаг 1. Перед лекцией**
Просмотрите [PROGRAM.md](PROGRAM.md): что будет в 90 минутах. Остальные файлы заранее открывать не нужно.

**Шаг 2. Первые 60 минут: слушаем**
Ссылки на инструменты из карты лежат в [07-resursy.md](07-resursy.md). Открывайте их по ходу или после лекции.

**Шаг 3. С 60-й минуты: практика с Claude**
1. В приложении Claude откройте вкладку **Code**, выберите окружение **Local**, затем **Open folder** и распакованную папку.
2. Отправьте Claude:

```text
Прочитай START.md в этой папке и начни со мной учебную практику.
```

3. Claude сам прочитает вакансию, критерии и задания ([01](01-jd-cpp-developer-hft.md), [02](02-kriterii.md), [05](05-praktika.md)), покажет план и остановится. Подтвердите план.
4. Дальше идите по этапам из [05-praktika.md](05-praktika.md): разбор учебных профилей ([03](03-uchebnye-profili.md)), сообщение кандидату по образцам ([04](04-obrazcy-pisem.md)), бонус: живой поиск, заметка, разбор в группе. Файлы 01-04 вручную открывать не нужно.
5. Результаты Claude сохраняет в папку `results/`.

**Шаг 4. Конец практики и после**
Соберите свой скилл по [06-svoj-skill-i-proverka.md](06-svoj-skill-i-proverka.md). Ресурсы из [07-resursy.md](07-resursy.md) разбирайте самостоятельно.

## До лекции

Пройдите [подготовку](00-podgotovka.md): приложение Claude, вкладка Code, расширение для Chrome и проверочный запрос. Если что-то не работает, сообщите до занятия.

## В начале практики

1. Скачайте репозиторий как ZIP (Code, Download ZIP) и распакуйте архив.
2. Во вкладке Code приложения Claude выберите окружение Local и откройте папку с этим README.
3. Отправьте запрос:

```text
Мы проводим учебный поиск C++ Developer (HFT).
Прочитай 01-jd-cpp-developer-hft.md, 02-kriterii.md и 05-praktika.md.
Проверь, доступны ли тебе веб-поиск и Claude in Chrome. Покажи короткий план и дождись моего подтверждения.
Рабочие результаты сохраняй в results/ внутри этой папки. Исходные материалы не меняй. Сообщения кандидатам не отправляй.
```

Можно короче: «Прочитай START.md в этой папке и начни со мной учебную практику». Дальше выполняйте [задания практики](05-praktika.md) вместе с ведущей. Минимум: разбор учебных профилей и сообщение кандидату. Бонус: живой поиск.

## Что проверять по ходу

Открывайте источники, сравнивайте выводы с цитатами и уточняйте задачу. Если страница недоступна, Claude должен сообщить об этом. Для продолжения упражнения есть вымышленные профили.

В `results/` останутся поиск, разбор профилей и версии сообщений. После занятия сохраните полезные правила по [руководству по сборке своего скилла](06-svoj-skill-i-proverka.md).

Вакансия и учебные профили вымышленные. Среди образцов писем есть два реальных обезличенных письма автора, остальные учебные. Готовый авторский скилл в материалы не входит.
